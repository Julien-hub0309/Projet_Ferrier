# Fonctionnalité inventaire.py : 

- Stock les machines avec un dictionnaire python, ne dois pouvoir être modifiable, il renvoie juste les informations avec la possibilité de télécharger un fichier .md de l'inventaire. 

- Le stock dois apparaitre en tableau ou les information suivant sont présent : 
	- Identifiant unique.
	- Nom du matériel.
	- Type de matériel (ordinateur, écran, imprimante, tablette, etc.).
	- Marque.
	- Modèle.
	- Numéro de série.
	- Date d'acquisition (optionnelle).
	- Localisation.
	- État (neuf, bon état, à réparer, hors service).
	- Observations ou commentaires.

## Sauvegarde des données
- Enregistrer les données dans un fichier.
- Charger les données au démarrage de l'application.
- Prévoir un format simple de stockage (JSON ou CSV).
